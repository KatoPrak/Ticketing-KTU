╔═══════════════════════════════════════════════════════════════════╗
║                      🏁 SETUP AWAL (SEKALI SAJA)                  ║
╚═══════════════════════════════════════════════════════════════════╝

1️⃣  BUAT REPOSITORY DI GITHUB
   → Login ke GitHub → New Repository → Nama: ticketing → Private

2️⃣  CONNECT LOCAL KE GITHUB (di Windows)
   cd d:\laragon\www\ticketing
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/username/ticketing.git
   git push -u origin main

3️⃣  CLONE DI SERVER UBUNTU
   ssh username@server-ip
   cd /var/www
   sudo git clone https://github.com/username/ticketing.git
   sudo chown -R $USER:$USER /var/www/ticketing
   cd /var/www/ticketing
   cp .env.production .env
   nano .env  # Edit DB_PASSWORD, dll
   chmod +x deploy.sh
   ./deploy.sh

╔═══════════════════════════════════════════════════════════════════╗
║                    🚀 COMMAND PENTING                             ║
╚═══════════════════════════════════════════════════════════════════╝

GIT COMMANDS:
  git status              → Cek file yang berubah
  git add .               → Add semua file
  git add file.php        → Add file tertentu
  git commit -m "msg"     → Commit dengan pesan
  git push origin main    → Push ke GitHub
  git pull origin main    → Pull dari GitHub
  git log --oneline       → Lihat history
  git diff                → Lihat perubahan

SERVER COMMANDS:
  ssh user@ip             → Login ke server
  cd /var/www/ticketing   → Masuk ke folder project
  git pull origin main    → Update code dari GitHub
  ./deploy.sh             → Deploy otomatis
  php artisan migrate     → Run migration
  php artisan cache:clear → Clear cache
  sudo systemctl restart nginx → Restart Nginx

╔═══════════════════════════════════════════════════════════════════╗
║                    ⚠️  TROUBLESHOOTING                            ║
╚═══════════════════════════════════════════════════════════════════╝

❌ ERROR: "Updates were rejected"
   ✅ SOLUSI: git pull origin main --rebase
              git push origin main

❌ ERROR: "Permission denied"
   ✅ SOLUSI: sudo chown -R www-data:www-data /var/www/ticketing
              sudo chmod -R 775 /var/www/ticketing/storage

❌ ERROR: "500 Internal Server Error"
   ✅ SOLUSI: sudo tail -f /var/log/nginx/error.log
              tail -f storage/logs/laravel.log
              php artisan cache:clear

❌ ERROR: "Database connection failed"
   ✅ SOLUSI: Cek .env file
              php artisan config:clear
              php artisan migrate:status
